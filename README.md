# Resonance — PWA Music

Персональный музыкальный плеер с домашней библиотекой и настраиваемым интерфейсом.

## Что уже работает в этой версии

- Адаптивный интерфейс: главная, библиотека, плейлисты и настройки.
- Поиск по названию, исполнителю, альбому и жанру.
- Сканирование локальной папки и чтение музыкальных тегов.
- Воспроизведение, пауза, предыдущий/следующий трек, перемотка и громкость.
- Избранное в локальном браузере.
- Настройка темы, акцентного цвета, фона, скругления, плотности, панели и анимаций.
- Сохранение собственных пресетов оформления.

## Требования

- Node.js 20+
- npm

## 1. Запуск музыкального сервера в Windows

Открой PowerShell в папке проекта:

```powershell
cd server
Copy-Item .env.example .env
npm install
npm start
```

Сервер по умолчанию сканирует `C:\Users\makhm\Music` и слушает порт 4317. Проверка: http://localhost:4317/api/health

Если папка другая, измени MUSIC_ROOT в server/.env. После добавления музыки нажми «Сканировать папку» в библиотеке.

## 2. Запуск интерфейса

Во втором окне PowerShell, из корневой папки проекта:

```powershell
npm install
npm run dev -- --host 0.0.0.0
```

Открой адрес Vite, который появится в консоли. На этом этапе используй интерфейс и сервер на ноутбуке. Для других устройств понадобится настроить адрес API на локальный IP ноутбука и разрешить доступ в брандмауэре Windows.

## Безопасность и ограничения

GitHub хранит исходный код, не аудиофайлы. Не пробрасывай порт 4317 напрямую в интернет: для удалённого доступа сначала настроим защищённый VPN/HTTPS. Сейчас избранное и настройки хранятся локально в браузере; полная синхронизация, плейлисты, тексты песен, DSP-эквалайзер, офлайн-загрузка и установка PWA — следующие этапы. Сервер не имеет пользовательской авторизации, поэтому пока не выставляй его в недоверенную сеть.
