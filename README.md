# Resonance Music

Личный музыкальный PWA-плеер. Музыка остаётся на твоём Windows-ноутбуке в `C:\Users\makhm\Music`, а браузер и телефон получают её с домашнего сервера.

## Запуск в Windows

1. Скачай **Code → Download ZIP** и распакуй архив.
2. Установи Node.js LTS (если ещё не установлен): https://nodejs.org/
3. Дважды щёлкни `1-УСТАНОВИТЬ.bat`.
4. Дважды щёлкни `2-ЗАПУСТИТЬ.bat`.
5. Добавь музыку в `C:\Users\makhm\Music`, затем выбери «Сканировать папку» в Resonance.

При запуске не закрывай окна сервера и Vite. Чтобы остановить приложение, используй Ctrl+C в соответствующих окнах.

## Доступ с телефона

1. Установи Tailscale на ноутбук и телефон: https://tailscale.com/download
2. Войди в один и тот же аккаунт Tailscale на обоих устройствах.
3. Запусти Resonance на ноутбуке через `2-ЗАПУСТИТЬ.bat`.
4. Дважды щёлкни `3-НАСТРОИТЬ-ТЕЛЕФОН.bat` и открой выведенный HTTPS-адрес на телефоне.
5. Добавь страницу на главный экран через меню браузера.

Ноутбук должен быть включён, подключён к сети и не должен переходить в сон. Не пробрасывай порт музыкального сервера на роутере и не публикуй его напрямую в интернете. Используй только доверенную приватную сеть Tailscale.

## Файлы для двойного щелчка

- `1-УСТАНОВИТЬ.bat` — установка пакетов (один раз).
- `2-ЗАПУСТИТЬ.bat` — локальный сервер и интерфейс.
- `3-НАСТРОИТЬ-ТЕЛЕФОН.bat` — HTTPS-доступ внутри Tailnet через Tailscale Serve.
- `4-ПРОВЕРИТЬ-СЕРВЕР.bat` — проверка доступности API.

## Реализованные возможности

- Сканирование музыкальной папки и чтение метаданных, включая встроенные обложки.
- Библиотека треков, страницы альбомов и исполнителей, поиск.
- Воспроизведение, пауза, переходы, перемотка и громкость.
- Очередь: добавление треков, просмотр и удаление.
- Избранное, плейлисты и история прослушивания.
- Перемешивание, режимы повтора, таймер сна.
- Восстановление выбранного трека и позиции при повторном открытии приложения.
- 10-полосный эквалайзер Web Audio API с пресетами и визуализатор.
- Тексты песен из соседних файлов `.lrc` и `.txt`.
- Редактор ID3-тегов MP3: название, исполнитель, альбом, жанр, год, дорожка и обложка.
- Перед записью тегов MP3 создаётся резервная копия; в настройках можно посмотреть копии и восстановить выбранную.
- Синхронизация избранного, плейлистов, истории, очереди, темы и параметров эквалайзера через домашний сервер.
- Экспорт и импорт настроек и пользовательских списков в JSON.
- Настраиваемые тема, акцентный цвет, фон, плотность, масштаб, размытие и расположение плеера.
- Установка как PWA; Media Session передаёт браузеру название, исполнителя, обложку и команды управления, если это поддерживается ОС/браузером.

## Ограничения, которые важно знать

- Запись тегов сейчас поддерживается **только для MP3**. Другие аудиоформаты доступны для сканирования и воспроизведения, но не для записи метаданных.
- Экспорт JSON сохраняет настройки, плейлисты, очередь, историю, избранное и параметры эквалайзера. Он **не включает аудиофайлы**.
- Резервные копии оригинальных MP3 хранятся локально в `server/backups` на ноутбуке.
- PWA кэширует оболочку приложения; полная загрузка музыки для офлайн-прослушивания пока не реализована.
- Управление с экрана блокировки и фоновое воспроизведение зависят от устройства, браузера, разрешений и энергосбережения ОС. Нужна проверка на конкретном телефоне.
- Crossfade, gapless playback и ReplayGain ещё не реализованы.
- Синхронизация работает через один домашний сервер и рассчитана на личное использование в приватной сети. Это не облачный сервис с отдельными аккаунтами и полноценным разрешением конфликтов между одновременными изменениями.
- Музыкальный API привязан к `127.0.0.1`; удалённые устройства должны открывать интерфейс через Vite/Tailscale Serve. Не меняй привязку API на `0.0.0.0`, не пробрасывай порт 4317 и не публикуй сервер напрямую в интернете. Tailscale должен быть включён на обоих устройствах.

## Проверки

В GitHub Actions выполняются:
- frontend: `npm run build` (TypeScript + Vite);
- server: `node --check index.js`;
- server unit tests: `npm test` (диапазоны HTTP Range, проверка путей и нормализация синхронизируемых данных).

Зелёная сборка подтверждает компиляцию и эти unit-тесты. Она не заменяет физическую проверку звука, Bluetooth, фона, Media Session и офлайн-поведения на ноутбуке и телефоне.


## Мобильная навигация и доступ к API

На телефонах нижняя панель навигации даёт быстрый доступ к главной, библиотеке, альбомам и избранному; разделы «Исполнители», «История», «Плейлисты» и «Настройки» находятся в меню «Ещё». Серверный API принудительно слушает только `127.0.0.1`; Tailscale Serve публикует только Vite-интерфейс внутри Tailnet, а Vite проксирует `/api` на локальный сервер.
