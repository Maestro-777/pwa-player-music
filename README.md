# Resonance Music

Личный музыкальный плеер: музыка хранится на ноутбуке, а слушать её можно через браузер или установленное PWA-приложение на телефоне.

## Самый простой запуск в Windows

**Больше не нужно вводить команды вручную.**

1. Скачай проект кнопкой **Code → Download ZIP** на GitHub и распакуй архив.
2. Установи Node.js LTS с https://nodejs.org/ (один раз).
3. Дважды щёлкни `1-УСТАНОВИТЬ.bat` и дождись надписи «ГОТОВО».
4. Дважды щёлкни `2-ЗАПУСТИТЬ.bat`. Откроется плеер.
5. Положи музыку в `C:\Users\makhm\Music` и нажми «Сканировать папку» в библиотеке.

Для остановки закрой два окна командной строки, которые открыл запуск.

Если музыка находится в другой папке, открой `server\.env` обычным Блокнотом и измени значение `MUSIC_ROOT`.

## Подключение телефона — один раз

Для защищённого доступа используем Tailscale. Это приватная сеть между твоими устройствами; не нужно открывать порты роутера и публиковать музыкальный сервер в интернете.

1. Установи Tailscale на ноутбук: https://tailscale.com/download
2. Установи приложение Tailscale на телефон.
3. Войди в один и тот же аккаунт на обоих устройствах и включи подключение.
4. На ноутбуке сначала запусти `2-ЗАПУСТИТЬ.bat`.
5. Затем дважды щёлкни `3-НАСТРОИТЬ-ТЕЛЕФОН.bat`. Команда Tailscale покажет защищённый HTTPS-адрес.
6. Открой этот HTTPS-адрес на телефоне (Tailscale должен быть включён) и добавь страницу на главный экран через меню браузера.

После этого на телефоне можно открыть библиотеку, выбрать альбом/трек и слушать. Ноутбук должен быть включён, подключён к сети и не должен засыпать. При перезагрузке ноутбука снова запускай `2-ЗАПУСТИТЬ.bat`.

## Файлы для двойного клика

- `1-УСТАНОВИТЬ.bat` — установка зависимостей (один раз).
- `2-ЗАПУСТИТЬ.bat` — запуск сервера и интерфейса.
- `3-НАСТРОИТЬ-ТЕЛЕФОН.bat` — включение HTTPS-доступа через Tailscale.
- `4-ПРОВЕРИТЬ-СЕРВЕР.bat` — проверка, что музыкальный сервер отвечает.

## Что уже работает

- Адаптивный интерфейс и настраиваемое оформление.
- Поиск по названию, исполнителю, альбому и жанру.
- Сканирование музыкальной папки и чтение тегов.
- Воспроизведение, пауза, переключение, перемотка и громкость.
- Избранное и сохранение настроек в браузере.
- PWA-оболочка для установки на главный экран.

## Важно знать

GitHub хранит код, а не аудиофайлы. Музыка остаётся на ноутбуке и передаётся телефону потоком. Для прослушивания ноутбук должен быть онлайн. Не пробрасывай порт 4317 на роутере и не публикуй сервер напрямую. Tailscale Serve предоставляет HTTPS внутри твоей приватной сети.

Синхронизация избранного между разными устройствами, полноценные плейлисты, тексты песен, DSP-эквалайзер и офлайн-загрузка музыки пока не реализованы — это отдельные следующие этапы.
