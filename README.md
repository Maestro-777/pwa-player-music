# Resonance — PWA Music

Персональный музыкальный плеер с домашней библиотекой, адаптивным интерфейсом и настраиваемым оформлением.

## Структура

- `src/` — React + TypeScript PWA-интерфейс.
- `server/` — локальный Node.js API для сканирования музыкальной папки Windows и выдачи аудиофайлов.
- `C:\\Users\\makhm\\Music` — планируемая основная папка музыкальной коллекции.

## Требования

- Node.js 20+
- npm

## Запуск интерфейса

```bash
npm install
npm run dev
```

## Запуск музыкального сервера (Windows)

```powershell
cd server
Copy-Item .env.example .env
npm install
npm start
```

По умолчанию API слушает порт 4317 и сканирует `C:\\Users\\makhm\\Music`.

Проверка: открыть `http://localhost:4317/api/health`.

## Важно о доступе из других устройств

GitHub хранит исходный код, а не музыку. Сервер должен работать на домашнем ноутбуке. Для доступа с телефона и из интернета потребуется отдельная настройка защищённого HTTPS-доступа (например, через VPN/Tailscale). Не публикуйте порт музыкального сервера напрямую в интернет.
